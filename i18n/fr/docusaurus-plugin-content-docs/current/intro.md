# Documentation GateCtr

**Une passerelle. Tous les LLMs.**

GateCtr s'intercale entre votre application et n'importe quel fournisseur LLM. Un simple changement d'endpoint. Sans modifier votre code. Contrôle total sur les coûts, le routage et l'observabilité.

## Ce que vous obtenez

- **-40% de tokens** — L'Optimiseur de Contexte compresse les prompts automatiquement
- **Pare-feu Budgétaire** — Des plafonds stricts par projet. Plus de factures surprises.
- **Routeur de Modèles** — GateCtr choisit le meilleur LLM pour chaque requête
- **Analytiques** — Chaque token, chaque coût, en temps réel
- **Webhooks** — Envoyez des événements vers Slack, Teams ou n'importe quelle URL
- **RBAC** — Contrôle d'accès par rôles pour les équipes
